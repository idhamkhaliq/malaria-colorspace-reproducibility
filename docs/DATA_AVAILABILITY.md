# Data availability

The malaria cell-image dataset analyzed in this study is a publicly available dataset described by Rajaraman et al. (2018). The raw image archive is not redistributed in this repository package. The repository includes the five frozen group-aware split manifests used for evaluation so that the exact train/validation/test assignments can be reconstructed after obtaining the source dataset from its authorized public source.
